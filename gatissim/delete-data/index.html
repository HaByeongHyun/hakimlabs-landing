같이씀 계정·데이터 삭제

같이씀(부부와 가족이 함께 쓰는 공동 가계부 앱)의 익명 계정과 가계부 데이터를 삭제하는 방법을 안내합니다.

관련 문서
같이씀 개인정보처리방침

1. 앱에서 삭제하는 방법

같이씀에는 회원가입이 없고, 앱을 처음 실행할 때 익명 계정을 만듭니다. 계정과 데이터는 앱 안에서 바로 삭제할 수 있습니다.

  1. 같이씀 앱을 엽니다.
  2. 설정으로 이동합니다.
  3. 가계부 나가기를 누릅니다.
  4. 삭제되는 것과 남는 것을 확인한 뒤 가계부 삭제하고 나가기(혼자 쓰는 경우) 또는 나만 나가기(둘이 쓰는 경우)를 누릅니다.
  5. 확인 창에서 삭제하고 나가기 또는 나가기를 누릅니다.

2. 삭제되는 데이터와 남는 데이터

혼자 쓰는 가계부

다음 데이터를 모두 삭제합니다. 남는 데이터는 없습니다.

  • 가계부와 가계부 이름
  • 지출 기록(이전에 지워 화면에서 숨긴 항목 포함)
  • 장보기 품목
  • 분류와 결제수단 설정
  • 초대코드와 중복 저장 방지용 요청 기록
  • 익명 계정

둘이 쓰는 가계부

삭제하는 데이터:

  • 내 가계부 참여 정보
  • 내 익명 계정
  • 내 중복 저장 방지용 요청 기록

남는 데이터:

  • 가계부와 공동 기록(지출, 장보기 품목, 분류, 결제수단)은 남은 사람이 계속 쓸 수 있도록 유지합니다. 이 기록에서 작성자 정보는 지웁니다.
  • 남은 사람의 요청 기록에는 무작위 ID 문자열이 남을 수 있습니다.

남은 사람이 나중에 “가계부 나가기”를 하면 그 가계부와 모든 기록이 삭제됩니다.

3. 처리 시점

확인 창에서 삭제를 확정하는 즉시 삭제합니다. 삭제한 데이터는 되돌릴 수 없습니다. 운영자는 별도의 데이터베이스 백업을 두지 않으며, 서버의 API·데이터베이스 로그는 1일 동안 보관된 뒤 삭제됩니다.

4. 앱을 이미 삭제한 경우

앱을 삭제하면 기기에 저장된 데이터는 삭제되지만, 서버에 저장된 가계부 데이터는 남습니다. 같이씀은 이름이나 이메일 없이 익명 계정을 쓰기 때문에, 앱이 없으면 운영자도 어느 계정이 이용자의 것인지 특정할 수 없습니다.

서버의 데이터를 지우려면 앱을 삭제하기 전에 “가계부 나가기”를 사용해 주세요.

5. 문의

삭제와 관련한 그 밖의 문의는 admin@hakimlabs.com으로 연락해 주세요. 개인정보 처리 전반은 같이씀 개인정보처리방침에서 확인할 수 있습니다.
