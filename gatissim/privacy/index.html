같이씀 개인정보처리방침

1. 개인정보의 처리 목적

운영자는 다음 목적으로만 개인정보를 처리하며, 목적이 바뀌면 미리 알리고 필요한 경우 동의를 받습니다.

  • 가계부 생성과 지출·장보기 기록의 저장, 조회, 집계
  • 초대코드를 이용한 가계부 공유와 두 기기 간 기록 동기화
  • 이용자가 요청한 영수증 사진에서 구매일·사용처·금액·분류 추출
  • 네트워크 오류 시 같은 기록이 중복 저장되지 않도록 하는 처리
  • 초대와 영수증 인식 기능의 과도한 반복 요청 제한

2. 처리하는 개인정보 항목

같이씀에는 회원가입이 없습니다. 앱을 처음 실행하면 무작위 사용자 ID로 된 익명 계정을 만듭니다. 이름, 이메일, 전화번호, 위치, 광고 ID는 수집하지 않으며, 광고·분석·크래시 보고 SDK를 사용하지 않습니다.

서버에 저장하는 정보

  • 익명 사용자 ID
  • 가계부 이름
  • 지출: 구매일, 금액, 사용처, 분류, 결제수단 이름, 분할 배분
  • 장보기 품목: 이름, 분류, 예상 금액, 구매 예정일
  • 분류와 결제수단 설정
  • 초대코드(발급 후 24시간 동안 1회만 사용 가능)
  • 중복 저장 방지를 위한 요청 기록(요청 ID와 그 요청의 입력값·응답)
  • 초대·영수증 인식 시도 횟수 기록

영수증 인식을 요청할 때만 처리하는 정보

이용자가 영수증 인식에 동의하고 요청하면, 선택하거나 촬영한 영수증·결제 내역 사진을 분석을 위해 전송합니다. 사진에 찍힌 정보(가게 이름, 금액, 결제 정보 일부 등)도 함께 전송될 수 있습니다. 같이씀은 원본 사진과 세부 품목을 저장하지 않고, 이용자가 확인하고 저장한 지출만 기록합니다.

기기에만 저장하는 정보

로그인 세션, 홈 화면 캐시(이번 달 금액과 사용처), 아직 서버에 저장되지 않은 대기 요청, 표시 설정, 영수증 인식 동의 여부를 기기에 저장합니다.

3. 보유·이용 기간과 파기

  • 서버에 저장한 정보는 이용자가 앱의 “가계부 나가기”로 삭제할 때까지 보유합니다. 삭제 범위는 6항과 계정·데이터 삭제 안내에 적었습니다.
  • 앱에서 지운 지출과 장보기 항목은 동기화와 중복 방지를 위해 화면에서만 숨기며, 가계부가 삭제될 때까지 서버에 남습니다.
  • 초대코드는 발급 후 24시간이 지나거나 한 번 사용되면 더 이상 쓸 수 없습니다.
  • 영수증 사진은 분석 요청을 처리하는 동안에만 다루며 같이씀 서버에 저장하지 않습니다.
  • 기기에 저장한 정보는 앱을 삭제하면 함께 삭제됩니다.
  • “가계부 나가기”로 삭제한 정보는 데이터베이스에서 즉시 지웁니다. 운영자는 별도의 데이터베이스 백업을 두지 않으며, Supabase의 API·데이터베이스 로그는 1일 동안 보관된 뒤 삭제됩니다.

4. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하거나 판매하지 않습니다. 가계부는 최대 2명이 함께 쓰며, 같은 가계부에 참여한 두 사람은 서로의 기록을 보고 수정할 수 있습니다. 이는 이용자가 초대코드로 직접 선택한 공유 기능이며 제3자 제공에 해당하지 않습니다.

같이씀은 유료 Gemini API를 사용합니다. Google은 보낸 사진과 응답을 제품 개선에 사용하지 않으며, 금지된 사용을 감지·방지하고 법령상 필요한 공개를 위해 제한된 기간 동안만 기록합니다(Gemini API 추가 서비스 약관).

국외 이전의 법적 근거: 「개인정보 보호법」 제28조의8 제1항 제3호(정보주체와의 계약 이행을 위해 필요한 처리위탁·보관으로서 이 방침에 공개한 경우). 영수증 사진은 이와 별도로 인식을 처음 요청할 때 앱에서 동의를 받은 뒤에만 전송합니다.

Supabase로의 이전은 기록을 저장하고 공유하는 데 꼭 필요하므로, 원하지 않으면 같이씀을 이용할 수 없습니다. Google로의 이전은 영수증 인식을 사용할 때만 일어나며, 이 기능을 쓰지 않으면 사진이 전송되지 않고 다른 기능은 그대로 이용할 수 있습니다.

6. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보를 열람·정정·삭제하거나 처리 정지를 요구할 수 있습니다.

  • 열람·정정: 앱에서 지출, 장보기 품목, 분류, 결제수단을 직접 확인하고 고칠 수 있습니다.
  • 삭제: 앱의 설정 → “가계부 나가기”를 사용합니다. 혼자 쓰는 가계부는 가계부와 모든 기록, 익명 계정을 즉시 삭제합니다. 둘이 쓰는 가계부는 내 참여와 익명 계정, 내 요청 기록을 삭제하고, 가계부와 공동 기록은 남은 사람에게 유지하되 기록의 작성자 정보를 지웁니다. 삭제한 정보는 되돌릴 수 없습니다. 자세한 내용은 계정·데이터 삭제 안내를 확인해 주세요.
  • 영수증 인식 거부: 영수증 인식에 동의하지 않거나 사용하지 않으면 사진을 전송하지 않습니다.
  • 문의: 그 밖의 요청은 admin@hakimlabs.com으로 보내 주세요. 같이씀은 익명 계정을 쓰기 때문에 운영자가 이메일만으로 이용자의 계정을 특정하기 어려울 수 있습니다. 삭제는 앱 안의 “가계부 나가기”를 먼저 이용해 주세요.

앱을 삭제해도 서버의 정보는 자동으로 삭제되지 않습니다. 서버의 정보를 지우려면 앱을 삭제하기 전에 “가계부 나가기”를 사용해야 합니다.

7. 안전성 확보 조치

  • 앱과 서버 사이의 모든 통신은 HTTPS로 암호화합니다.
  • 가계부 기록은 해당 가계부에 참여한 사람만 조회할 수 있도록 데이터베이스 접근 권한을 제한합니다.
  • 서버 관리용 비밀키와 영수증 분석 API 키는 앱에 넣지 않고 서버에만 둡니다.
  • 영수증 원본 사진은 저장하지 않습니다.

8. 기기 권한

  • 카메라: 영수증을 촬영할 때 사용합니다.
  • 사진: 영수증이나 결제 내역 사진을 고를 때 사용합니다.

두 권한 모두 선택 사항입니다. 허용하지 않아도 지출을 직접 입력하는 기능은 그대로 쓸 수 있으며, 기기 설정에서 언제든지 바꿀 수 있습니다.
