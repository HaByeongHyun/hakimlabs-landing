리마일 개인정보처리방침

기기에 저장하는 정보

리마일은 차량 모델·연식·연료 유형, 직접 입력한 주행거리와 변경 이력, 정비 항목·교체 주기·날짜·당시 주행거리·메모, 알림 설정을 이 기기에 저장해요. 정비 이력을 보여주고 다음 교체 시점을 계산하기 위해 사용해요. 회원가입과 계정 기반 서버 동기화는 제공하지 않아요.

서버 전송과 추적

차량과 정비 기록을 리마일 운영 서버로 자동 전송하지 않아요. 광고, 사용자 추적, 이용 분석 기능을 사용하지 않아요. 위치·연락처·사진·마이크를 이용하지 않으며 실제 주행거리를 자동 수집하지 않아요.

파일 백업과 복원

파일로 백업을 선택하면 차량 정보와 메모를 포함한 JSON 파일을 만들어요. 별도로 암호화되지 않은 평문 파일이므로 저장하거나 공유할 위치를 신중하게 선택해 주세요. 선택한 파일 앱·클라우드·공유 대상의 데이터 처리는 해당 서비스의 정책을 따라요. 복원하면 현재 데이터 전체를 교체하며, 복원 직전 안전사본 1개를 앱 전용 공간에 보관해요. 안전사본은 앱 삭제나 기기 분실에 대비한 외부 백업을 대신하지 않아요.

알림 권한

교체 예정일 알림을 직접 켤 때 기기의 알림 권한을 요청해요. 허용하면 기간 기준이 있는 항목을 기기 안에서 예약하고, 잠금 화면 등에 정비 항목과 교체 예정 안내가 표시될 수 있어요. 거부해도 기록과 교체 예정 조회를 사용할 수 있어요. 거리 기준 상태는 직접 입력한 주행거리로 계산하며 거리 도달 알림을 자동 감지하지 않아요.

보관과 삭제

기록은 직접 삭제하거나 앱 데이터를 제거할 때까지 기기에 보관돼요. 기록 삭제 뒤 앱 세션 중 마지막 삭제 1건을 취소할 수 있어요. 다음 삭제·전체 복원·앱 프로세스 종료 시 취소 정보는 사라져요. Android의 앱 저장공간 삭제 또는 운영체제의 앱 삭제로 앱 전용 데이터를 제거할 수 있어요. 앱 정리하기나 보관 기능은 데이터를 유지할 수 있으므로 전체 삭제와 구분해 주세요. 외부에 저장한 백업과 운영체제의 기기·클라우드 백업은 별도로 관리하거나 삭제해야 해요. 기기 설정에 따라 앱 데이터가 운영체제 백업에 포함될 수 있어요.

외부 페이지와 문의

개인정보와 앱 이용에 관한 문의는 아래 운영자 이메일로 보내 주세요. 외부 페이지를 열면 브라우저와 해당 웹사이트의 정책에 따라 접속 정보가 처리될 수 있어요. 이 화면의 데이터 처리 안내와 문의 이메일은 인터넷 연결 없이 읽을 수 있어요.
